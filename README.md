# ⚡ Reflex Arena — Human Benchmark Web Game

A fast, zero-dependency 3-in-1 cognitive & reflex benchmark game built in **pure HTML, CSS, and Vanilla JavaScript**. Runs at 60 FPS on both mobile and desktop with local high-score tracking and 1-click score sharing.

### 🎮 Play Live
👉 **[Play Reflex Arena](https://rahulcodes-ai.github.io/reflex-arena/)**

### ✨ 3 Game Modes
- **⚡ Reaction Time:** Measure your visual reflex speed in milliseconds.
- **🧠 Memory Grid:** Progressive 4x4 pattern-recall challenge.
- **🎯 Aim Trainer:** 15-target precision & speed drill with accuracy tracking.

### 🛠️ Tech Stack
- Pure HTML5, CSS3, Vanilla JavaScript (Single-file architecture, zero frameworks)
- Hosted via **GitHub Pages**
